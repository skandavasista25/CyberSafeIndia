Password Safety

Most account takeovers don't involve clever hacking — they involve a weak or reused password. Here's how to fix that.

The essentials

Building better password habits

Strong Password Creation

Use a long passphrase of 4–5 unrelated words rather than a single dictionary word with symbols swapped in — length matters more than complexity. Avoid names, birthdays, or anything visible on your social media.

Password Managers

A password manager generates and stores a unique, complex password for every account, so you only need to remember one master password. This removes the temptation to reuse passwords across sites.

Two-Factor Authentication (2FA)

2FA adds a second check — an authenticator app code, a security key, or a biometric scan — so a stolen password alone isn't enough to log in. Prefer an authenticator app over SMS codes where possible, since SMS can be intercepted.

Password Reuse Risks

If one website you use is breached, criminals test that same email-and-password combination on banks, email, and shopping sites — a practice called "credential stuffing." Reusing passwords turns one small leak into many account takeovers.

Quick reference

Best password practices

Do

  • Use a different password for every important account.
  • Turn on 2FA for email, banking, and social media accounts.
  • Update a password immediately if a service reports a data breach.
  • Use a reputable password manager to generate and store passwords.

Don't

  • Don't reuse the same password across multiple sites.
  • Don't use easily guessed details like birthdays or "password123".
  • Don't share passwords over chat, email, or phone calls.
  • Don't save passwords in plain-text notes or unprotected files.
